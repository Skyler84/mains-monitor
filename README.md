# ESP32C6 Mains Voltage Monitor

This project hopes to create a simple, safe, open source Mains Voltage monitor for anyone who needs/wants it. For me, I've had multiple power cuts, devices killed due to what I suspect is faulty mains voltage and more. This project hopes to provide logging for any power anomolies that might come my way.

## Hardware

I tried to make this as simple as possible.
- ESP32C6 Supermini (Available from aliexpress for <£3 if you look around)
- Mains->5V power supply module (Available from aliexpress for ~50p)
- 230V->6V Mains isolation transformer (Available from RS for ~£2.50)
- 3*100K resistors
- 1*10K resistor
- 1*100uF capacitor
- IEC plug
- some assorted wire/heatshrink as necessary.

I'll post a schematic in due course and design a PCB which should be available from JLC for ~£5. Currently i've just assembled everything on a prototying board.
